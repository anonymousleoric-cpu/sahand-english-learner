# 📚 زبان‌آموز سهند — Sahand Language Learner

## 🔊 صداقت دربارهٔ تلفظ

صدای تلفظ از موتور گفتار (**Android TTS**) خود دستگاه پخش می‌شود. کیفیت صدا به موتور نصب‌شده روی گوشی کاربر بستگی دارد و ممکن است در همهٔ دستگاه‌ها طبیعی نباشد یا به دادهٔ صوتی انگلیسی نیاز داشته باشد (نصب از تنظیمات سیستم). این محدودیت در خود اپ نیز صادقانه توضیح داده شده است.

## 📲 دانلود APK (از GitHub Actions)

APK به‌صورت خودکار با هر push ساخته می‌شود:

1. به تب **Actions** این مخزن بروید: `https://github.com/anonymousleoric-cpu/sahand-english-learner/actions`
2. روی آخرین اجرای موفق **«Build Android APK»** کلیک کنید (تیک سبز ✅)
3. در پایین صفحه، بخش **Artifacts**، فایل **`Sahand-App-APK`** را دانلود کنید
   *(برای دانلود artifact باید با حساب GitHub خود لاگین باشید)*
4. فایل ZIP را باز کنید؛ داخل آن **`app-debug.apk`** قرار دارد
5. فایل APK را به گوشی منتقل و نصب کنید (فعال‌کردن «نصب از منابع ناشناس» لازم است)

> APK از نوع **debug** است و بدون امضا با هر گوشی اندرویدی ۷.۰ به بالا (API 24+) نصب می‌شود.

## 🛠 ساخت از سورس

**نیازمندی‌ها:** Android Studio (Hedgehog+) یا JDK 17 + Android SDK 34

```bash
git clone https://github.com/anonymousleoric-cpu/sahand-english-learner.git
cd sahand-english-learner
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

یا در Android Studio: `Build ▸ Build Bundle(s)/APK(s) ▸ Build APK(s)`

## 🏗 معماری فنی

- **Kotlin 2.0** + **Jetpack Compose** (Material 3) — رابط کاملاً راست‌به‌چپ فارسی با فونت **وزیرمتن**
- **MVVM** با ViewModel + StateFlow
- **Hilt** برای تزریق وابستگی
- **Room** برای محتوا و پیشرفت کاربر (محتوا در اولین اجرا از JSON داخل APK بارگذاری می‌شود)
- **DataStore** برای تنظیمات
- **Navigation Compose** با نوار پایین ۵ بخشی
- بدون هیچ کتابخانهٔ شبکه — کاملاً آفلاین

```
app/src/main/java/com/sahandsoft/englishlearner/
├── data/db          # Room: موجودیت‌ها، DAOها، دیتابیس
├── data/seed        # بارگذاری محتوای JSON از assets
├── data/prefs       # DataStore تنظیمات
├── data/repo        # منطق پیشرفت، آمار، SRS
├── domain           # الگوریتم SRS، تولید آزمون، ابزار تاریخ
├── util             # TTS، پشتیبان‌گیری
├── di               # ماژول‌های Hilt
└── ui               # تم، ناوبری، کامپوننت‌ها و ۱۸ صفحه
```
